### Shortcuts

- ctrl + N create new file
- ctrl + SHIFT + N create new folder
- ctrl + T - global search for symbols
- ctrl + R - toggle right panel
- ctrl + J - toggle bottom panel
- ctrl + B - toggle left panel
- ctrl + SHIFT + B - open outline panel
- ctrl + SHIFT + O - open outline panel inline
- ctrl + P search project files
- ctrl + F local find
- ctrl + SHIFT + F global project search
- alt + ESC - show completions
- win + ESC - show word completions
- ctrl + SHIFT + K - delete line
- ctrl + L  select line
- ctrl + SHIFT + L - select all word occurrences
- ctrl + SHIFT + I - format
